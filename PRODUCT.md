# UI Gallery

## Platform

Web. A small React/Vite application, also embedded in the existing React website at `https://www.harshith.com/ui`.

## Purpose

Show real interfaces built by Harshith Vaddiparthy and connect visible design decisions to their source code. The audience includes designers, developers and prospective collaborators evaluating the work.

## Scope

The repository contains the gallery, a public project catalog, original capture records, optimized screenshots and case notes. Featured applications remain separate repositories with their own setup requirements and licenses.

The gallery needs no API key, account or backend. It supports category filtering, alternative screen views and full-size image access. It preserves the existing Harshith visual identity.

## Publication standard

Every entry needs a real implementation, clear contribution credits, verified license/source links and safe screenshots. Use explicit sample/demo captions where applicable. Exclude private records, credentials, confidential code and unsupported outcome claims.
